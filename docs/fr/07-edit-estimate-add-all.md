# 7. Corriger une estimation et « Tout ajouter »

Corrigez une estimation avant de l'enregistrer et ajoutez d'un coup tous les aliments reconnus.

**Prérequis :** Une estimation de Gemini (scénario 06).

## Étapes

1. Sur une carte, touchez le bouton jaune **Modifier**. Changez le repas, le nom ou les grammes. Les calories et les macros sont recalculées à partir de l'estimation d'origine.
2. Vous pouvez ajouter ou retirer un ingrédient du plat.
3. Quand il y a deux aliments ou plus, touchez **Tout ajouter** pour les enregistrer d'un coup dans le repas choisi.

## Résultat

Chaque entrée garde sa propre copie de la photo.

> **Manquant :** Captures d'écran de toutes les étapes.
