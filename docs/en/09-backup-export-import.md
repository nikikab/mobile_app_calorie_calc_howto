# 9. Backup: export and import

Save all data in one ZIP file and bring it back.

**Prerequisites:** None.

## Steps

1. Open **Settings** and scroll to **Backup**.

   ![Backup: export and import – 1](../../media/09-backup-export-import/en-01-backup-section.png)

2. **Export** saves the diary, weight, profile and photos in one ZIP file through the system file picker. The Gemini key is not included.
3. **Import** restores data from such a file. It REPLACES everything after a confirmation and is validated first.

## Result

Data lives on the phone and is lost on uninstall or when changing phones, so export now and then.
