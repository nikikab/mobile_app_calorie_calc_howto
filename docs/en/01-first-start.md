# 1. First start and language

What you see when you first open KaloCalc and how to change the language.

**Prerequisites:** None. The app is free and needs no account.

## Steps

1. Open KaloCalc. The start screen is the **Diary**: an empty day, the daily goal (calories and macros) and the four meals.

   ![First start and language – 1](../../media/01-first-start/en-01-empty-diary.png)

2. Tap the language ("🇬🇧 EN ▾") at the top right. Pick English, Bulgarian, German, French or Spanish. The whole interface switches at once and the choice is remembered.

   ![First start and language – 2](../../media/01-first-start/en-02-language-picker.png)


## Result

On first run the app follows the phone language if it is one of the five, otherwise English.
