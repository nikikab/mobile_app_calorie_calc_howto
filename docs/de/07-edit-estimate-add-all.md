# 7. Schätzung korrigieren und „Alle hinzufügen“

Korrigiere eine Schätzung vor dem Speichern und füge alle erkannten Speisen auf einmal hinzu.

**Voraussetzungen:** Eine Gemini-Schätzung (Szenario 06).

## Schritte

1. Tippe auf einer Karte auf die gelbe Schaltfläche **Bearbeiten**. Ändere Mahlzeit, Name oder Gramm. Kalorien und Makros werden anhand der ursprünglichen Schätzung neu skaliert.
2. Du kannst eine Zutat des Gerichts hinzufügen oder entfernen.
3. Bei zwei oder mehr Speisen tippe auf **Alle hinzufügen**, um sie auf einmal in der gewählten Mahlzeit zu speichern.

## Ergebnis

Jeder Eintrag behält seine eigene Kopie des Fotos.
