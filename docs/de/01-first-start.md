# 1. Erster Start und Sprache

Was du beim ersten Öffnen von KaloCalc siehst und wie du die Sprache änderst.

**Voraussetzungen:** Keine. Die App ist kostenlos und braucht kein Konto.

## Schritte

1. Öffne KaloCalc. Der Startbildschirm ist das **Tagebuch**: ein leerer Tag, das Tagesziel (Kalorien und Makros) und die vier Mahlzeiten.

   ![Erster Start und Sprache – 1](../../media/01-first-start/en-01-empty-diary.png)

2. Tippe oben rechts auf die Sprache („🇬🇧 EN ▾“). Wähle Englisch, Bulgarisch, Deutsch, Französisch oder Spanisch. Die ganze Oberfläche wechselt sofort, und die Wahl wird gespeichert.

   ![Erster Start und Sprache – 2](../../media/01-first-start/en-02-language-picker.png)


## Ergebnis

Beim ersten Start folgt die App der Handysprache, wenn sie zu den fünf gehört, sonst Englisch.
